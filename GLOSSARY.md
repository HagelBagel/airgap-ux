# AirGap UX

UX researchers turn interview transcripts into tagged quotes, insights and scored Jobs-to-be-Done job cards.

## Language

**User**:
A signed-in researcher. A User owns Projects.
_Avoid_: Account, researcher (as a data term), member

**Project**:
The unit of research a User opens and works in; every Transcript, Tag, Insight and Job Card belongs to exactly one Project.
_Avoid_: Vault, workspace, study, folder
